## 🌿 About Plantify

**Plantify — Discover. Learn. Grow.**

Plantify is a responsive plant discovery website built with React. It allows users to explore different plant species, search by common or scientific name, and view detailed information about plants, trees, and flowers.

## Features

- Browse different plant species.
- Search by common or scientific name.
- View detailed plant information.
- Explore available plant images and characteristics.
- Navigate between pages using React Router.
- Responsive design for different screen sizes.

## Technologies i have used

- React
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router
- Axios
- Perenual API

## Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Plantify
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

##  Data Source

Plantify uses the [Perenual API](https://perenual.com/) to retrieve plant data and available details.
